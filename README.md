# UpStartInterns-Internship-Task-01---Sensor-and-Actuator
A temperature sensor that lights up an LED in response to change in temperature, on a simulator (Wokwi)
The LED lights up, after a 2 second interval, when temperature is greater than 35.0 degree Celsius. If the temperature is equal to 35.0 degree Celsius or less than it, the LED does not light up.
